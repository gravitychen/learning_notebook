## 讲解与幻灯片规则

- 所有解释入口先讲现象、变量的物理或算法含义、希望达到的效果，再说明计算如何实现目标；随后连接公式、Python 与实际数值核对。主路径先建立直觉，详细求导放在“查看数学依据”的按需展开层。不可把辅助量误称为物理量，也不可把先验假设当成事实。

- 按知识依赖和推导顺序组织前后页；每页说明与上一页的联系，把关键推导拆成可跟随的小步骤。
- 首次引入符号时解释它的定义、作用及物理或算法含义；同一概念在前后页保持符号一致，并明确迭代轮次与上下标的含义。
- 使用简化例子或更换符号时，明确它与原问题中各变量的对应关系、适用范围及区别，避免把类比误认为原问题的精确推导。
- 每幅图标明它展示的变量、空间、轮次和色标，并联系对应的公式与代码；以少量文字配合图像，详细推导可按需展开。

## 参考

细节模式中的“代码与数值”默认展示每轮六个小步的 Python / NumPy，可切换到 JavaScript。Python 代码直接来自可下载的 [solver.py](solver.py)，与网页中的周期边界、热扩散模糊和两通道各向异性 TV 保持一致。x_next、z_next、u_next 表示新一轮，z、u 是旧一轮；lam 对应 λ。点击图像选择像素，或输入行列坐标（0–63），再点“代入并计算”，查看实际迭代数组里的输入、中间量和结果。

Python 是经过数值核对的等价实现；网页仍在浏览器中计算，不运行 Python。安装 NumPy 后，可在自己的 Python 环境中调用 `x, z, u = initialize(b)`，再用 `state = admm_step(b, z, u, lam, rho)` 迭代，并将 `state['z']`、`state['u']` 作为下一轮输入。b 是二维观测图像，不能用清晰真值代替。`node test.mjs` 会使用本机 `python` 与 NumPy 对照每个展示代码片段及完整更新的实际数组。

x 步使用整幅图像的 FFT 求解：像素坐标 [i,j] 与频率坐标 [p,q] 分开选择。面板展示一个频点的复数分子、分母和商，再对照全体频点逆 FFT 后的像素结果；频点的商不等于同坐标的像素亮度。面板与求解器调用同一个 solveXStep。显示值保留 8 位有效数字，运算使用完整 Float64 精度。
