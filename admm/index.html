找一张既解释观测、又接近目标梯度的图像

我们实际看到了什么？

相机给我们的是模糊、带噪声的观测 b。x 是正在猜测的清晰图像，H 是已知的模糊过程。把 x 送进 H，得到“如果这张猜测是真的，相机应该看到什么”——也就是 Hx。

候选清晰图 x→ H 模糊 →预测观测 Hx↔ 比较 ↔实际观测 b

下方左图是固定的 b，右图是本轮求出的新 x。它们不是要直接长得一样；应该比较的是 Hx 与 b。

这一轮希望图像发生什么变化？

一方面，让预测观测 Hx 接近 b；另一方面，让图像的实际梯度 Dx 接近当前给出的目标 zᵏ − uᵏ。下方中图展示这个目标的一个方向，求解时两个方向一起参与。

z 是辅助梯度，u 是协调 Dx 与 z 的算法修正量；它们不是场景亮度，也不是真实边缘的标准答案。新 x 要在两个要求之间做权衡，而不是满足其中一个就结束。

观测要求：Hx ≈ b共同约束梯度目标：Dx ≈ zᵏ − uᵏ→本轮新图 xᵏ⁺¹

怎样把这两个要求变成可计算的目标？

分别用平方误差衡量“离要求还有多远”，再相加。ρ 越大，本轮越重视当前梯度目标。此时 zᵏ、uᵏ 固定，只调整 x。

minₓ {½‖Hx − b‖₂² + ρ/2 ‖Dx − (zᵏ − uᵏ)‖₂²}

第一项衡量预测观测的偏差；第二项衡量梯度目标的偏差。导数告诉我们，改变每个像素会怎样改变这些代价；最优位置的两部分导数相互平衡，不要求两项误差分别为零。

为什么误差通过 Hᵀ 回到像素，而不是 H？ ↓

先看一个像素怎样影响相机，再看误差怎样汇总回来

模糊把一个像素的影响扩散到哪里？

想象只把候选图像中的一个像素 xⱼ 调亮一点。在模糊成像中，相机上的一片位置都会随之变亮。Hᵢⱼ 就是这个像素对第 i 个观测的影响权重。这里 j 是像素编号，i 是观测编号，均不是迭代轮次。

一个像素 xⱼ 的变化→ 按 H 的第 j 列扩散 →多个观测发生变化

我们希望用观测误差决定什么？

现在各个位置已经有预测偏差 Hx − b。我们想知道：“如果调亮 xⱼ，总平方误差会增加还是减少，变化有多大？”这才是对 xⱼ 求导的含义。

需要把每个观测的误差，乘上该像素影响它的权重，再汇总。不是把模糊过程倒放，也不是直接恢复出一个真实像素。

各处观测误差 (Hx − b)ᵢ× 同一影响权重 Hᵢⱼ，再求和 →像素 xⱼ 的导数

这种汇总为什么叫转置？

固定像素 j，遍历观测 i，取的是 H 的第 j 列。将这一列用作一行，与观测误差做加权求和，就是 Hᵀ 的第 j 行。对所有像素同时做，就得到 Hᵀ(Hx − b)。

若像素有 n 个、观测有 m 个，H 为 m × n。误差是 m 维，回到像素的导数应为 n 维，Hᵀ 的 n × m 尺寸也与这个方向一致。

查看数学依据：把这次汇总写成链式法则 ↓
(Hx)ᵢ = Σⱼ Hᵢⱼxⱼ，∂(Hx)ᵢ/∂xⱼ = Hᵢⱼ
∂/∂xⱼ [½Σᵢ(Hx − b)ᵢ²] = Σᵢ(Hx − b)ᵢHᵢⱼ
ΣᵢHᵢⱼ(Hx − b)ᵢ = [Hᵀ(Hx − b)]ⱼ

平方求导的 2 与 ½ 抵消；每个观测再乘它对 xⱼ 的导数 Hᵢⱼ。转置来自这组索引关系，而不是把 H 取逆。

回到本页代码，应该看到什么？

本例 H 是对称的热扩散模糊，因此 Hᵀ = H。Python 中的实数频率响应 h_hat 同时表示二者；一般不对称算子则不能这样简化。Hᵀ(Hx − b) 表示代价的导数，不直接等于更新后的 x；实际 x 更新还同时考虑梯度目标。

查看数学依据：从两个要求得到正规方程 ↓

固定 b、H、D、ρ、zᵏ、uᵏ，对候选 x 求导。此处的 ∇ₓ 是目标函数对图像变量的导数，与图像空间差分 Dx 不同。

∇ₓ [½‖Hx − b‖₂²] = Hᵀ(Hx − b)
∇ₓ [ρ/2 ‖Dx − zᵏ + uᵏ‖₂²] = ρDᵀ(Dx − zᵏ + uᵏ)

Dᵀ 与 Hᵀ 同样来自链式法则，将梯度空间的偏差汇总回图像空间。两部分相加为零：

Hᵀ(Hx − b) + ρDᵀ(Dx − zᵏ + uᵏ) = 0
HᵀHx − Hᵀb + ρDᵀDx − ρDᵀzᵏ + ρDᵀuᵏ = 0

含 x 的留在左边，其余移到右边；求出的最优 x 记为 xᵏ⁺¹：

(HᵀH + ρDᵀD)xᵏ⁺¹ = Hᵀb + ρDᵀ(zᵏ − uᵏ)

ρ > 0 时目标为凸二次函数，梯度为零即达到全局最小值。本例 H 的频率响应均大于零，因此解唯一。右侧 zᵏ − uᵏ 的符号来自移项，含义没有变化。

实际怎样算，算完又看什么？

本例 H、D 使用相同的周期边界，可以用 FFT 将整组正规方程变成各频点的除法，再逆 FFT 得到新图像。下方 Python 的 numerator、denominator 和 x_next 对应这三个环节。

点击下方图像选像素，再点“代入并计算”：先看两个方向的目标梯度，再看频率空间分子、分母，最后看逆 FFT 后的亮度。频点 [p,q] 不等于像素 [i,j]，一个频点会影响整张图。

完成一轮后，可以在整体模式观察重建及残差；观测偏差与梯度偏差不保证每小步同时下降。真值只供对照，不参与更新。

软阈值这一步如何推导？先看 z 要实现什么 ↓

让辅助梯度更稀疏，同时保留当前输入中的明显变化

梯度图里，什么对应平坦区域和边缘？

x 是图像亮度，Dx 是相邻像素的亮度差。平坦区域通常变化小，物体边界通常变化大。下方红蓝色显示梯度的正负方向，颜色深浅表示幅度；它不是物体本身的颜色。

本例假设清晰图像由较多平坦区域和较少边界构成。因此，我们希望减少细碎起伏，并保留明显变化。但小梯度也可能是真实细节，大梯度也可能来自噪声；这是先验假设，不是真假边缘的判别器。

z 和 v 分别在这个目标中做什么？

Dx 是当前图像实际产生的梯度；z 是用来承接稀疏先验的一份辅助梯度，不是另一张亮度图。前一步已将新梯度与旧修正量合成输入 vᵏ⁺¹ = Dxᵏ⁺¹ + uᵏ；u 是算法协调量，所以 v 不能直接当成纯粹的图像梯度。

新图像 xᵏ⁺¹→ 差分 D →实际梯度 Dxᵏ⁺¹+ 旧 uᵏ →输入 vᵏ⁺¹→ 软阈值 →辅助梯度 zᵏ⁺¹

下方左图是 v，右图是新 z；两者使用相同色标，可以直接比较哪些变化被削弱。z 的更新不会立即改写当前图像 x；它会通过后续 u 更新和下一轮 x 求解影响重建。

怎样兼顾“更稀疏”和“别偏离输入太远”？

一方面，希望 z 的许多分量为零，表达大部分区域平坦的假设；另一方面，不能把输入 v 的变化全部抹掉。用两个代价表达这两个要求：

min_z {λ|z| + ρ/2 (z − v)²}

这里暂时只看同一像素、同一方向的一个数 z、v。第一项鼓励 z 靠近零，第二项惩罚它远离 v；完整数组的各分量独立做相同计算，这是本例各向异性 TV 的性质。

z 向 0 靠近：绝对值代价减小权衡z 离 v 更远：平方偏差代价增大→选总代价最低的 z

这个权衡会让数值怎样变化？

以默认 λ = 0.015、ρ = 0.10 为例，阈值为 0.15。比较以下三种输入：

输入 v输出 z发生了什么
0.300.15正的大变化向零缩小
0.080小变化归零
−0.30−0.15负的大变化也向零缩小

大输入保留符号，但幅度减小；小输入直接归零。这解释了希望在梯度图上看到的变化，也解释了为什么真实细节可能被削弱。下面再回答：收缩量为什么恰好是 λ/ρ？

查看数学依据：为什么阈值是 λ/ρ？ ↓

固定 xᵏ⁺¹、uᵏ，原目标中只依赖 x 的数据项是常量，可省略：

zᵏ⁺¹ = argmin_z {λ‖z‖₁ + ρ/2 ‖z − vᵏ⁺¹‖₂²}

‖Dxᵏ⁺¹ − z + uᵏ‖₂² = ‖z − vᵏ⁺¹‖₂²，因为平方范数整体换号不变。各向异性 TV 可以拆成各分量的 λ|z| + ρ/2(z − v)²；下面 z、v 仅表示一个分量。

正的大输入：让最小点落在 z > 0

|z| = z ⇒ λ + ρ(z − v) = 0 ⇒ z = v − λ/ρ

只有 v > λ/ρ，候选解才满足 z > 0。

负的大输入：让最小点落在 z < 0

|z| = −z ⇒ −λ + ρ(z − v) = 0 ⇒ z = v + λ/ρ

只有 v < −λ/ρ，候选解才满足 z < 0。

小输入：为什么最小点停在零？

|z| 在零点有尖角，普通导数不存在，其次梯度为区间 [−1, 1]。凸目标达到最小值的条件是总次梯度包含 0：

z = 0 时：0 ∈ λ[−1, 1] − ρv
⇔ ρv ∈ [−λ, λ] ⇔ |v| ≤ λ/ρ

所以阈值两端也取零。ρ > 0 使标量目标严格凸，每个分量都有唯一最优解。合并三个区间，并恢复数组与轮次：

zᵏ⁺¹ = sign(vᵏ⁺¹) · max(|vᵏ⁺¹| − λ/ρ, 0)
= soft(Dxᵏ⁺¹ + uᵏ, λ/ρ)

sign、绝对值、max 都逐分量计算。λ/ρ 来自解最优条件，不是额外选出的第三个参数。

回到 Python 和真实图像，怎样核对？

下方 np.sign(v) * np.maximum(np.abs(v) - lam / rho, 0) 依次对应保留方向、缩小幅度、将小于阈值的幅度截为零。

接下来比较 Dxᵏ⁺¹ 与新 z 的偏差，再更新 u，使下一轮继续协调。软阈值只是每轮的一部分，不等于对最终图像做完了一次去噪。
